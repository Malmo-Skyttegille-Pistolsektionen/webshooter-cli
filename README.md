# Webshooter Client

## Build


```bash
hatch build
```

## Install

`pip install <wheel generated by hatch build>` 

e.g. `pip install dist/webshooter_client-0.1.dev27-py3-none-any.whl`

## Run

### From installed pip package

`wscli --help`

### Direct in git repo

`$src/webshooter_client/command.py --help`


## Linting and Testing

```bash
hatch run lint:black src tests 
hatch run lint:flake8

hatch run test:pytest tests
```

### webshooter.rc config file

Place in home directory, i.e. `~/webshooter.rc`


```
[global]
unicode = True
card = xx
club = aa-bbb
token = <token from web browser, copy from Firefox: Web Developer Tools -> Storage -> Local Storage -> token>
```

All configurations are optional.
