# Webshooter Client

A Python CLI client for interacting with [webshooter.se](https://www.webshooter.se), the Swedish shooting competition platform.

## Quick Start

### Installation

```bash
pip install <wheel generated by hatch build>
```

Example: `pip install dist/webshooter_client-0.1.dev27-py3-none-any.whl`

### Configuration

Create `~/.webshooter.rc` (optional):

```ini
[global]
unicode = True
card = xx
club = aa-bbb
token = <your-token-here>
```

**Getting your token:**
1. Log in to [webshooter.se](https://www.webshooter.se)
2. Open browser developer tools (F12)
3. Navigate to: Storage → Local Storage → token
4. Copy the token value

All configuration options can be overridden via command-line arguments.

### Usage

```bash
# List competitions for 2026
wscli competitions --year 2026

# Show results for a specific competition
wscli results --competition 283

# Show signups
wscli signups --competition 283 --club 12-239

# Get help
wscli --help
```

## Development

### Prerequisites

- Python 3.10+
- [Hatch](https://hatch.pypa.io/)

### Build

```bash
hatch build
```

### Run from Source

```bash
# From git repo (without installation)
hatch run python src/webshooter_client/command.py --help

# From installed package
wscli --help
```

### Testing

```bash
# Run all tests
hatch run dev:pytest tests

# Run with coverage
hatch run dev:pytest --cov=src/webshooter_client --cov-report=html tests

# Run specific test file
hatch run dev:pytest tests/unit/webshooter_client/commands/test_competition_list.py
```

### Code Quality

```bash
# Lint code
hatch run dev:flake8
```

## Features

- ✅ List competitions by year
- ✅ View competition results with filtering by club/card
- ✅ View signups and start times
- ✅ Export competitions to iCal format
- ✅ Medal statistics
- ✅ Support for all competition types (Military, Precision, Field, PointField)
- ✅ Configurable via CLI args or config file
- ✅ Type-safe with dataclasses and type hints

## Architecture Highlights

- **Layered architecture** - Clear separation: CLI → Commands → Services → API → Models
- **Strategy pattern** - Formatters and parsers for different competition types
- **Singleton config** - Centralized configuration management
- **Custom exceptions** - Clear error handling and messages
- **Type safety** - Dataclasses with type hints throughout

See [ARCHITECTURE.md](ARCHITECTURE.md) for detailed architectural documentation.
